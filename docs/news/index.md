# Changelog

## personnelSelectionUtility 0.5.18

- Added install-time safeguards that create the installed `doc/`
  directory before vignette indexing, without keeping `inst/doc` in the
  editable source tree. This avoids the interactive prompt about
  deleting `inst/doc` while preventing vignette-installation failures on
  Windows/R 4.6.
- Removed unused `vignettes/logo.png` and `vignettes/logo.svg` files;
  pkgdown now uses the package logo only through the page header.
- Kept the pkgdown logo display restricted to individual article
  headers; index pages and the navbar do not display the package logo.
- No statistical computations changed.

## personnelSelectionUtility 0.5.16

- Removed the manually maintained `inst/doc` placeholder so development
  builds no longer ask whether `inst/doc` should be deleted. The
  vignette documentation should be generated by R during package build
  rather than stored manually in the editable source.
- Removed manual logo chunks from the four vignettes so the logo appears
  only once in pkgdown article pages, in the article title/header
  generated by pkgdown.
- Removed the manual README logo image to avoid an oversized duplicate
  logo on the pkgdown home page.
- Updated `pkgdown/extra.css` to hide the automatic logo on
  article-index and other index pages while keeping it in individual
  article page headers.

## personnelSelectionUtility 0.5.15

- Added a small `inst/doc/.keep` file so the installed package always
  has a `doc/` directory available while R installs vignette indices on

## personnelSelectionUtility 0.3.0

- Builds on the previous 0.2.0 API rather than replacing it.
- Adds
  [`tr_multivariate_equal_cutoff()`](https://rgempp.github.io/personnel-selection-utility/reference/tr_multivariate_equal_cutoff.md)
  to reproduce Thomas-Owen-Gunst-style equal-cutoff tables from a target
  joint selection ratio.
- Adds
  [`tr_binomial_success_probability()`](https://rgempp.github.io/personnel-selection-utility/reference/tr_binomial_success_probability.md)
  for finite-sample success probabilities after a Taylor-Russell
  calculation.
- Aligns
  [`tr_solve()`](https://rgempp.github.io/personnel-selection-utility/reference/tr_solve.md)
  more closely with `TaylorRussell::TR()` by using a non-negative
  validity interval by default and handling PPV values that do not
  exceed the base rate defensively.
- Adds staged multiple-hurdle simulation through
  [`multiple_hurdle_selection_staged()`](https://rgempp.github.io/personnel-selection-utility/reference/multiple_hurdle_selection_staged.md)
  and
  [`compare_selection_systems_staged()`](https://rgempp.github.io/personnel-selection-utility/reference/compare_selection_systems_staged.md),
  allowing each stage to be a composite of predictors.
- Adds
  [`selection_utility_from_z()`](https://rgempp.github.io/personnel-selection-utility/reference/selection_utility_from_z.md)
  for Ock-Oswald-style utility calculations from expected criterion
  performance.
- Adds diagnostic and SDy helpers from the Holling-oriented source
  functions:
  [`coefficient_of_determination()`](https://rgempp.github.io/personnel-selection-utility/reference/coefficient_of_determination.md),
  [`forecasting_efficiency()`](https://rgempp.github.io/personnel-selection-utility/reference/forecasting_efficiency.md),
  [`sdy_cost_accounting()`](https://rgempp.github.io/personnel-selection-utility/reference/sdy_cost_accounting.md),
  [`sdy_crepid()`](https://rgempp.github.io/personnel-selection-utility/reference/sdy_crepid.md),
  [`correct_r_direct_range_restriction()`](https://rgempp.github.io/personnel-selection-utility/reference/correct_r_direct_range_restriction.md),
  and
  [`utility_regression_diagnostics()`](https://rgempp.github.io/personnel-selection-utility/reference/utility_regression_diagnostics.md).
- Extends
  [`boudreau_utility()`](https://rgempp.github.io/personnel-selection-utility/reference/boudreau_utility.md)
  with `contribution_margin` and `variable_value_convention` to make the
  `(1 + V)` versus `(1 - V)` interpretation explicit.
- Updates README, vignette, mapping file, tests, and manual pages for
  the expanded 0.3.0 API.

## personnelSelectionUtility 0.2.0

- Adds the Thomas-Owen-Gunst multivariate Taylor-Russell model via
  [`tr_multivariate()`](https://rgempp.github.io/personnel-selection-utility/reference/tr_multivariate.md)
  using
  [`mvtnorm::pmvnorm()`](https://rdrr.io/pkg/mvtnorm/man/pmvnorm.html).
- Adds flexible univariate Taylor-Russell solving via
  [`tr_solve()`](https://rgempp.github.io/personnel-selection-utility/reference/tr_solve.md).
- Adds a model taxonomy aligned with criterion scale and selection
  structure.
- Adds Sturman-style restricted canonical validity and
  incremental-validity utilities.
- Adds simulation helpers to compare compensatory and multiple-hurdle
  selection systems.
- Adds Boudreau-style discounted utility, probation-period adjustment
  helpers, multi-attribute utility, Pareto frontiers, adverse-impact
  summaries, and Monte Carlo uncertainty propagation.
- Harmonizes argument names: `validity`, `selection_ratio`, `base_rate`,
  `sdy`, `n_selected`, `tenure`, and `cost`.
