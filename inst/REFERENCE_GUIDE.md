# Reference guide for documentation examples

The function help pages in `personnelSelectionUtility` include brief literature comments in the `examples` section. These comments are intended to help users map each computation to the relevant methodological tradition.

Core mappings:

Taylor-Russell classification utility: Taylor and Russell (1939); Cascio (1980).

Multivariate Taylor-Russell / multiple cutoffs: Thomas, Owen, and Gunst (1977); Waller (2024).

Continuous expected criterion gain: Naylor and Shine (1965).

Monetary selection utility: Brogden (1946, 1949); Cronbach and Gleser (1965); Schmidt et al. (1979).

Financial and flow extensions: Boudreau (1983, 1991); Boudreau and Berger (1985); Holling (1998).

Baseline and multiple-outcome utility: Sturman (2001).

Compensatory versus multiple-hurdle simulation: Sackett and Roth (1996); Ock and Oswald (2018).

AUC and effect-size conversion helpers: Hanley and McNeil (1982); Rice and Harris (2005); Kerby (2014); Salgado (2018).

Pareto and fairness-oriented selection design: De Corte, Lievens, and Sackett (2007); De Corte, Sackett, and Lievens (2011).

Use `citation("personnelSelectionUtility")` for the package citation and consult the vignettes for model-level guidance.
